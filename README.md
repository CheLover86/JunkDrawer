Whats in the drawer:

# StringStuff
A quick collection of stringutils inside of C, such as strcpy, strup, strlen, and printf. More to be added soon... Maybe!

# Mini_Malloc
With both malloc and free, you are now able to allocate memory and free it! Uses both forward and backward coalescing, with an implicit free list.

# StatsCalc
Quick calculator that computes Mean, Min, max of a vector.
